## Phase 1 · 跑通复现（D2–D5）

- [ ] 登录 Radeon Cloud，配置实例（详见 `04-cloud-runbook.md`）
- [ ] 环境自检：GPU 可见、挂载正确、Git commit 匹配固定版本
- [ ] 启动官方模型 server，验证推理链路（action 形状 `[25,14]`）
- [ ] 单任务闭环评测（`adjust_bottle`，`test_num 10`）跑通
- [ ] 记录 baseline 成功率与耗时 → `experiments/`

## Phase 2 · 后训练实验（D5–D18）

- [ ] 决定路线：**LoRA**（快、省显存）还是 **全参数 SFT**（更强、更贵）
- [ ] LoRA 冒烟（100 steps）→ 验证训练/合并/推理链路
- [ ] 正式训练（LoRA 1000/5000 steps，或 SFT）
- [ ] 小规模闭环验证选点（建议 4–8 个代表性任务，不要每次跑全量）
- [ ] 参数/数据消融，记录每次实验（`experiments/_TEMPLATE.md`）

## Phase 3 · 全量评测 + 固化（D18–D24）

- [ ] 选定最优 checkpoint
- [ ] 4/8 卡全量评测（100 task × 10 ep，**预留 16–19 小时**）
- [ ] 保存结果 JSON、日志、成功率汇总到 `/workspace` 并拉回本地
- [ ] 整理提交物：模型/代码/说明文档按要求格式

## Phase 4 · 提交（D24–D26）

- [ ] 备份所有产出、截图留证

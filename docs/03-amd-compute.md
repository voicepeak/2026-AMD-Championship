# 03 · AMD 算力申请

AMD 为本次赛事提供基于 **Radeon Cloud** 的专项算力 + **ROCm** 开源 AI 软件栈。

## 硬件与环境

| 项 | 内容 |
|---|---|
| 平台 | Radeon Cloud Global — https://radeon-global.anruicloud.com/ |
| GPU | **W7900D 48GB GDDR6** × 4 或 8 |
| 软件栈 | ROCm 7.2.1 + PyTorch 2.9.1 |
| 开放时间 | **2026-09-15 14:00 – 2026-10-26 20:00** |
| 规模 | 基础 200 张 GPU，动态调整 |
| 用途限制 | 仅限本次比赛；用于其他场景将回收资格 |

## 申请流程（4 步，按顺序）

### Step 1 · 完成赛事报名
- 比赛入口：https://tianchi.aliyun.com/competition/entrance/532514
- 记录 **天池团队 ID**（申请算力时要填）

### Step 2 · 注册 AMD 开发者计划（ADP）
- 注册链接：https://developer.amd.com.cn/login?source=sSEUZ7cAA

### Step 3 · 加入官方赛事交流群
- 报名 + ADP 注册完成后加入，获取**算力申请入口**和后续通知

### Step 4 · 团队提交 GPU 资源申请
- 申请入口：https://developer.amd.com.cn/contestgpu_apply01
- 填写：**大赛注册团队 ID**
- **每位成员都要填**（成员名单是 AMD 追加资源、赛后积分与证书发放的依据）
- 以**队伍为单位排队**，按提交顺序发放
- 每队指定 **1 名队长**负责接收算力并与 AMD 对接

## 算力发放规则

- 符合条件的队伍获得专属 **Radeon GPU Credits**，**无需自备训练算力**
- 以团队为单位、按阶段发放
- 详见官方指南：`Radeon-Cloud-User-Guide/AMD_VLA_Contest_Compute_Rules.md`
  （在 https://github.com/AMD-DEV-CONTEST/Embodied-AI-Challenge-AMD-Platform-2026-09 仓库内）

## 可做的工作

- RoboTwin 任务评测
- LingBot-VLA 2.0 模型复现与训练

## AMD 专项福利

| 福利 | 说明 |
|---|---|
| 专属算力 | 符合条件的队伍获 Radeon GPU Credits |
| 开发环境 | W7900D 48GB + ROCm 软件栈 |
| 积分 | 用 AMD 算力完成并提交 → 额外 100 积分（新注册共 250） |
| 曝光 | 优秀项目获官方社区报道、技术直播、ROCm 曝光 |
| 实物 | 决赛前三额外获 Radeon RX 9000 系显卡 |
